# CI

## 01. 워크플로 파일

| 파일 | 언제 | 하는 일 |
| --- | --- | --- |
| `ci.yml` | PR → main | 테스트 (`./gradlew test`) — 브랜치 보호의 필수 검사 이름 `test` |
| `_test.yml` | 다른 워크플로가 부름 | 테스트 잡 하나 (재사용) |

## 02. 지금 상태

- PR 마다 테스트가 돎.
- 이미지 빌드 · 배포 워크플로는 아직 없음 — 운영 환경(인프라)이 정해지면 팀과 함께 추가.
  - 이미지 태그는 커밋 앞 7자리 · `latest` 를 쓰지 않을 예정.
